\# Julie-Tech-Learning



A personal sandbox repo for learning Git and GitHub fundamentals — branching, committing, pushing, and organizing small projects across languages.



\## Structure



This repo doesn't build out projects on `main`. Instead, each language track lives on its own long-running branch:



| Branch | Contents |

|---|---|

| `python-practice` | Python projects: calculator, password strength checker, network port scanner |

| `csharp-practice` | C# projects: bank account class |



\## Why branches instead of folders?



Normally branches are short-lived — you branch off `main`, do work, merge back in, and delete the branch. Here I'm intentionally keeping branches around per language as a way to practice `git checkout`, `git branch`, and switching contexts. It's not how you'd structure a production repo, but it's a good way to build muscle memory with branching commands.



\## Projects



\*\*Python (`python-practice` branch)\*\*

\- `calculator/` — simple CLI calculator (+, -, \*, /)

\- `password-checker/` — scores password strength based on length and character variety

\- `network-scanner/` — basic TCP port scanner (localhost/authorized hosts only)



\*\*C# (`csharp-practice` branch)\*\*

\- `bankaccount/` — a `BankAccount` class with deposit/withdraw and balance tracking
